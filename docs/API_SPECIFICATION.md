# 📡 Rishta Aunty — API Specification

This document provides complete documentation for the backend API endpoints provided by the **Rishta Aunty** Python Flask serverless service.

---

## 1. Base URL

- **Local Development:** `http://localhost:5000`
- **Vercel Production:** `https://rishta-aunty.vercel.app` (or your deployment domain)

All API endpoints support both the `/api/*` prefix (standard for Vercel serverless functions) and root routes for local backwards compatibility.

---

## 2. Endpoints Overview

| Method | Path | Description | Authentication |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/roast` or `/roast` | Analyzes candidate profile & generates satirical biodata dossier | None |
| `GET` | `/api/health` or `/health` | Healthcheck & system status probe | None |
| `GET` | `/` | Serves the root static `index.html` file | None |
| `GET` | `/<filename>` | Serves static assets (`style.css`, `app.js`, etc.) | None |

---

## 3. Detailed Endpoint Specs

### 3.1. `POST /api/roast`

Generates an affectionate Pakistani matrimonial roast based on candidate profile metadata and repository telemetry.

#### Request Headers
| Header | Value | Required |
| :--- | :--- | :--- |
| `Content-Type` | `application/json` | Yes |

#### Request Body Schema

```json
{
  "profile": {
    "login": "string (Required) - GitHub username",
    "name": "string (Optional) - Full display name",
    "bio": "string (Optional) - Bio description",
    "public_repos": "number (Required) - Total public repositories",
    "followers": "number (Required) - Follower count",
    "following": "number (Required) - Following count",
    "created_at": "string (Required) - ISO timestamp of account creation",
    "avatar_url": "string (Optional) - Avatar image URL"
  },
  "repos": [
    {
      "name": "string - Repository name",
      "description": "string - Repository summary",
      "stargazers_count": "number - Star count",
      "language": "string - Primary language (e.g. 'Python', 'TypeScript')",
      "fork": "boolean - Whether repo is a fork"
    }
  ]
}
```

#### Example Request Payload (`curl`)

```bash
curl -X POST https://rishta-aunty.vercel.app/api/roast \
  -H "Content-Type: application/json" \
  -d '{
    "profile": {
      "login": "torvalds",
      "name": "Linus Torvalds",
      "bio": "Creator of Linux & Git",
      "public_repos": 7,
      "followers": 220000,
      "following": 0,
      "created_at": "2011-09-03T15:26:22Z"
    },
    "repos": [
      {
        "name": "linux",
        "description": "Linux kernel source tree",
        "stargazers_count": 185000,
        "language": "C",
        "fork": false
      }
    ]
  }'
```

## 4. Error Handling & Status Codes

Rishta Aunty guarantees non-crashing behavior by falling back gracefully. However, malformed requests receive standard HTTP errors:

| Status Code | Description | Cause | Remediation |
| :--- | :--- | :--- | :--- |
| `200 OK` | Success | Roast generated successfully (via AI or rule engine). | Normal operation. |
| `400 Bad Request` | Invalid Input | Missing `"profile"` or `"profile.login"` in request body. | Ensure valid JSON with GitHub user metadata. |
| `404 Not Found` | Unknown Route | Request to unmapped path. | Check route prefix (`/api/roast` vs `/roast`). |
| `500 Internal Error` | Unhandled Error | Syntax error or environment crash. | Check serverless execution logs on Vercel. |

## 5. Client Integration Code Snippets

### JavaScript (ES6+ / Fetch API)
```javascript
async function fetchRishtaRoast(profileData, repoData) {
  const response = await fetch('/api/roast', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      profile: profileData,
      repos: repoData
    })
  });

  if (!response.ok) {
    throw new Error(`Server returned HTTP ${response.status}`);
  }

  const result = await response.json();
  console.log('Source:', result.source);
  console.log('Title:', result.data.title);
  return result.data;
}
```

### Python (`requests`)
```python

response = requests.post("https://rishta-aunty.vercel.app/api/roast", json=payload)
```
