## 🌟 The Lore & Concept

In South Asian (Pakistani, Indian, Bangladeshi, and diaspora) culture, few institutions evoke as much dread, laughter, and anxiety as the **Rishta Aunty** (Matchmaking Auntie). 

Equipped with razor-sharp intuition, maternal suspicion, and a bottomless cup of doodh patti chai, she scrutinizes every prospective bachelor:
- *Kitna kama leta hai?* (What's his earning potential?)
- *Ghar ke kaam aate hain ya sirf mobile chalata hai?* (Does he do domestic chores or just stare at screens?)
- *Khandaan kaisa hai?* (What is the family reputation?)

### Enter Rishta Aunty for Coders
**Rishta Aunty** takes this legendary cultural trope and applies it with unfiltered, affectionate satire to the modern software developer. Instead of asking for physical family trees and gold jewelry receipts, Aunty inspects your **GitHub Public Profile**:

```
Your Public Repos         ──►  Evaluated as "Dahej" (Marriage Dowry)
Your Stargazer Count      ──►  Rated as "Khandani Izzat" (Family Mohalla Prestige)
Your Follower Ratio       ──►  Scrutinized as "Milansar" (Sociability & Networking)
Your Top Programming Lang ──►  Classified into "Khandani Tech Gotra" (Baradari Caste)
Your Commit Habits        ──►  Diagnosed as Domestic Superpowers vs "Topi Drama"
```

The output is an authentic, retro-software-styled **Official Matrimonial Biodata Dossier** equipped with an animated **Rubber Stamp** (*SCENE OFF HAI ❌*, *LADKI WALAY SOCHENGAY ⚠️*, or *RISHTA PAKKA! 💍*), ready to download as a high-resolution PNG card or share directly to WhatsApp family groups!

## 🎯 Why This Makes the Internet Fun

Built specifically for **GDG Live Pakistan — Chai aur Code Ep#2** under the hackathon theme **"Make Internet Fun"**, Rishta Aunty addresses the modern web's sterile, corporate homogeneity:

1. **Zero Artificial Mockups:** Real-time ingestion of live public data. Anyone on Earth with a GitHub account can type their handle and get roasted instantly.
2. **Culturally Resonant, Halal Humor:** 100% focused on relatable developer sins—npm fatigue, tutorial hell, direct pushes to main, ghosting abandoned repos, and 4 AM dark mode habits. No derogatory jokes regarding religion, sects, gender, or personal appearance.
3. **Bulletproof Resilience (Zero Blank Screens):** Built with dual-tier fallback engines (Python backend + Client JS). If the AI provider has latency, rate limits, or goes offline, the app computes instant rule-based satirical roasts in $<5\text{ ms}$.
4. **Pure Tactile Joy:** Heavy, physical Neobrutalist buttons that physically depress, animated tea cups that wobble, stamps that slam with spring physics, and vibrant candy-colored cards.

## ⚡ Core Features & Capabilities

- [x] **Zero-Framework Vanilla Stack:** 100% pure HTML5, CSS3, and ES6+ JavaScript on the client. Absolutely zero React, Vue, Svelte, Vite, or npm bundle dependencies.
- [x] **Pure Python Backend:** Serverless WSGI micro-service built with Flask and Python 3.9+, ready for turnkey deployment on Vercel Edge.
- [x] **GroqCloud LPU Acceleration:** Sub-second AI synthesis powered by `llama-3.3-70b-versatile` on Groq's high-speed Language Processing Unit.
- [x] **Dual-Tier Offline Matrix:** Deterministic algorithmic fallback engine in both Python (`fallbacks.py`) and JavaScript (`fallbacks.js`) inspecting 10+ signals.
- [x] **Interactive Neo-Glassmorphism UI:** 3.5px solid black ink borders, offset hard drop shadows, floating ambient gradient mesh orbs, and specular frosted highlights.
- [x] **Permanent Connected Input Badge:** Integrated Neobrutalist input group with a dedicated `github.com/` monospace addon that never covers user input.
- [x] **1-Click Retinal PNG Export:** High-contrast canvas rasterization via `html2canvas` at scale 2, ensuring vibrant, non-faded candy colors on WhatsApp and Twitter.
- [x] **Native Social Sharing:** Pre-formatted, emoji-rich WhatsApp message generator, Twitter / X broadcast intents, and 1-click clipboard copying.
- [x] **Live Demo Quick-Picks:** One-tap demo chips for hackathon judges (*Linus Torvalds*, *Dan Abramov*, *shadcn*, *Sindre Sorhus*, *Lee Robinson*).

## 🧠 GroqCloud LPU AI Engine

When configured with a free API key from [GroqCloud Console](https://console.groq.com/), Rishta Aunty harnesses `llama-3.3-70b-versatile` executing on Groq's high-speed Language Processing Unit (LPU).

### Prompt Engineering Architecture
1. **System Persona:** Aunty acts as a 58-year-old elite matrimonial matchmaker from Gulberg/DHA Lahore with 35 years of arranged marriage experience.
2. **Contextual Ingestion:** Receives the candidate's username, biography, repo count, follower/following ratios, total stars, top language, and latest repo descriptions.
3. **Structured Grammar Enforcement:** Output is strictly constrained to valid JSON containing:
   - `title`: Satirical developer matrimonial title.
   - `gotra`: Technical baradari lineage.
   - `matchScore`: Numerical rating between `10` and `99`.
   - `stampStatus`: Rubber stamp decision string.
   - `habits`: Exactly 3 daily domestic developer rituals.
   - `redFlags`: Exactly 3 technical warning signs.
   - `auntyVerdict`: A biting maternal closing judgment in authentic Roman Urdu.

## 📸 High-Contrast 1-Click Retinal PNG Export

When sharing a biodata on WhatsApp groups or Twitter, images must pop with crystal clarity.

Naive canvas captures of glassmorphic elements appear washed-out because `html2canvas` does not capture the browser's dynamic background mesh. Rishta Aunty implements an **Export Optimization Pipeline**:

```javascript
// app.js - High-Contrast Export Hook
const canvas = await html2canvas(biodataCard, {
  scale: 2, // 2x Retina Resolution
  useCORS: true,
  backgroundColor: '#faf5ed',
  onclone: (clonedDoc) => {
    const card = clonedDoc.getElementById('biodata-card');
    card.classList.add('export-mode'); // Forces 100% solid saturated colors
  }
});
```

- **`.card-frame.export-mode`** strips all translucent opacity, rendering a solid `#ffffff` canvas.
- Replaces washed-out 70% pastel tints with **100% solid Neobrutalist candy colors** (`#fde047`, `#f472b6`, `#38bdf8`, `#4ade80`).
- Freezes stamp animations at `opacity: 1` with deep crimson (`#991b1b`), amber (`#92400e`), and emerald (`#065f46`) ink.

## 💻 Local Installation & Development Guide

### Prerequisites
- Python 3.9+ (Python 3.10, 3.11, 3.12, 3.13, 3.14 fully supported).
- Modern web browser (Chrome, Edge, Firefox, Safari).

### Step-by-Step Walkthrough

```powershell
# 1. Clone the repository
git clone https://github.com/abdulhayykhan/Rishta-Aunty.git
cd Rishta-Aunty

# 2. Create a virtual environment
python -m venv .venv

# 3. Activate the virtual environment
# Windows (PowerShell):
.\.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# 4. Install production dependencies
pip install -r requirements.txt

# 5. (Optional) Configure GroqCloud AI
cp .env.example .env
# Edit .env and paste your GROQ_API_KEY=gsk_...

# 6. Launch the local Flask server
python app.py
```

Open your browser and navigate to **`http://localhost:5000`**. The application is immediately operational!

## 🧕 Cultural Slang & Roman Urdu Lexicon

A quick translation cheat-sheet for the authentic Pakistani terms used across the bureau:

- **Topi Drama:** Fake posturing or pretentious excuses (e.g. writing 500 lines of documentation for a project that doesn't work).
- **Phannay Khan:** A self-proclaimed hotshot who acts like a tech emperor without actual achievements.
- **Chuss:** A low-effort, flat action or disappointing commit message (`"fix bug"`, `"asdasd"`).
- **Shashkay:** Flamboyant, flashy flourishes designed to show off to onlookers.
- **Scene Off Hai:** Complete failure / deal cancelled (*"Phupho ne rishta cancel karwa diya"*).
- **Scene Full On Hai:** 100% success; celebrations and sweets are in order!
- **Khandani Gotra:** Developer caste / tech lineage (*"Node_Modules Baradari"*).
- **Biryani Mein Elaichi:** That one annoying technical red flag that ruins an otherwise good developer profile.

For the comprehensive cultural glossary, explore [docs/CULTURAL_SLANG_LEXICON.md](docs/CULTURAL_SLANG_LEXICON.md).
